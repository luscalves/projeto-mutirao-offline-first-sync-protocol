Projeto Mutirão: Sincronização Distribuída em Saúde Comunitária
Este repositório contém o código-fonte do Projeto Mutirão, uma arquitetura de software offline-first projetada para Agentes Comunitários de Saúde operando em áreas com conectividade nula ou intermitente. O sistema substitui o paradigma de mutação de estado tradicional por um Log de Operações imutável. Utilizando Relógios Lógicos Híbridos (HLC) para ordenação causal e Tipos de Dados Replicados Livres de Conflitos (CRDTs - LWW-Register e OR-Set) para resolução determinística de conflitos, o protocolo garante a convergência dos dados e a consistência eventual entre dispositivos móveis e o servidor, sem perda ou duplicação de cadastros.
